# 오르페이아 VN 추가 에셋 생성 지침 (3차)

비주얼 노벨 모드(프롤로그·1장)에 필요한 에셋입니다. 1·2차 에셋은 모두 반영되어 있다는 전제입니다.

## 연결 방식

`assets/`에 파일명 그대로 넣으면 사이트가 시작할 때 감지해 해당 장면에 사용합니다. 없는 동안은 다음처럼 대체됩니다.
- 교관·하랑 스탠딩: 이름표만 표시
- 일상 배경: 야간 관제실 등 기존 배경
- 오르페이아 추가 표정: 기본·칭찬·걱정 스탠딩
- 이벤트 CG: 표시하지 않음

## 새 인물 설정 (생성 AI에 함께 전달)

- **도윤재 교관** — 하늘선 종합관제센터 수석 관제사, 50대. 무뚝뚝하고 말수가 적지만 신입을 끝까지 지켜보는 사람. 입버릇은 "기록해 둬", 늘 종이컵 커피를 들고 있음.
- **채하랑** — 주인님의 동기 수습 관제사. 밝고 시끄러운 철도 마니아로 긴장하면 차량 제원을 외움. 오르페이아와 티격태격하는 친구.

## 공통 아트 방향

- 오르페이아: 기존 제공 PNG를 최우선 캐릭터 참조로 사용. 오르페이아는 긴 은색 머리, 선명한 녹색 눈, 청록색 리본, 약 3등신의 귀여운 SD 애니메이션 캐릭터. 얼굴형·앞머리·눈매·복식·소품은 참조와 일치. 깨끗하고 섬세한 선화, 부드러운 셀 채색, 머리카락과 의복 재질의 정돈된 명암. 짙은 남색·청록·절제된 금색 팔레트, 은은한 차가운 윤곽광. 기존 홀로그램 PNG와 같은 수준의 마감.
- 새 인물: 기존 오르페이아 PNG와 같은 화풍으로 새 인물을 그린다: 약 3등신의 SD 애니메이션 비율, 깨끗하고 섬세한 선화, 부드러운 셀 채색, 짙은 남색·청록·절제된 금색 팔레트, 은은한 차가운 윤곽광. 오르페이아의 얼굴형·은발·녹색 눈·메이드 복장을 복제하지 않는다. 같은 인물의 표정 차분은 자세·배율·발 기준점을 고정하고 표정과 손만 바꾼다.
- 배경: 한국 철도 배경의 애니메이션 ADV 미술. 짙은 남색과 청록색, 정돈된 셀 채색, 섬세한 선화. 인물 없는 배경. 기존 bg_*.png 배경과 같은 시점 높이·채도·선 굵기로 맞춘다.
- 스탠딩은 VN 화면 하단에 발을 맞춰 세웁니다. 같은 인물의 차분은 캔버스 크기·발 위치·머리 높이를 반드시 통일합니다.
