# 오르페이아 비상관제 ADV

## 실행

함께 제공한 `오르페이아-비상관제-ADV.html`을 브라우저에서 열면 에셋과 데이터가 포함된 단일 파일로 실행됩니다. 프로젝트 폴더에서는 `dist/index.html`을 열어도 됩니다. 20개의 PNG를 상대경로로 읽으므로 dist의 폴더 구조를 유지하세요. 브라우저의 한국어 음성 지원에 따라 대사 읽기 음색과 지원 여부가 달라집니다. 마이크 녹음은 HTTPS 또는 로컬 서버의 지원 브라우저에서 사용할 수 있습니다.

## 훈련 흐름

시나리오 선택 → 현장 인물/상황 수신 → 관제 질문 → 4개 행동·대사 중 선택 → 정답·오답 해설 및 지령 발화 복습 → 다음 수신 → 결과입니다. 선택지 순서는 출동할 때마다 섞입니다. 숫자 1~4로 선택하고 Enter로 다음 단계로 이동할 수 있습니다. 입력창·선택창과 시나리오 목록을 사용하는 동안 답변 단축키는 동작하지 않습니다.

‘먼저 말하기 모드’를 켜면 선택지가 숨겨집니다. 수신을 보고 먼저 말하거나 메모한 뒤 선택지를 확인하세요. 45초 연습 타이머와 내 대사 녹음/재생을 사용할 수 있습니다. 녹음은 현재 화면에서만 재생되고 서버로 전송되지 않습니다. 선택지를 공개하거나 다른 화면으로 이동하면 녹음이 정리됩니다. 작성한 메모는 답변 후 정답 대사와 비교할 수 있지만 자동으로 채점하지 않습니다.

대사는 원문 조치를 발화형으로 변환한 학습용 예시입니다. 실제 현장 지령, 내부 화면 확인, 관계부서 협조, 평가관에게 설명하는 상황판단을 구분해 표시합니다. 공식 표준 무전문구의 전사본이나 최신 규정 검증본은 아닙니다. 선택지에는 의도적으로 틀린 행동과 대사도 포함되며, 채점 후 정답과 오답 이유를 확인하도록 구성했습니다.

## 원문 보존과 디자인

업로드된 「오르페이아 비상관제 훈련소.html」의 도시철도 26개·철도 48개 시나리오, 432단계를 보존했습니다. 원래의 수신문·질문·4개 조치 보기·정답 인덱스·해설·근거 쪽수·핵심 요약은 변경하지 않았습니다. 여기에 1,728개 대사 예시와 장면 역할 정보를 추가했습니다.

플레이어가 관제사이고, 오르페이아는 기관사·역장·현장 점검 담당·승무원 역할의 연락 상대 또는 학습 보좌입니다. 일러스트 개편으로 스탠딩 7종과 브리핑·구조·소방·전력·신호·재해·위험물 홀로그램 7종을 새로 제작했습니다. 기존 현장 홀로그램 4종과 복창·복구완료 홀로그램 2종을 함께 사용합니다. 이전에 빈 통신 창으로 표시되던 280단계를 포함해 모든 432단계에 그림을 지정했습니다. 직접 보고는 현장 수신, 설명문은 상황 안내로 표시합니다. 첫 화면의 역할 버튼으로 전신을 전환해 볼 수 있습니다. 정답·오답 피드백과 결과 화면은 새 메이드 스탠딩을 사용합니다.

최고 정답 개수·오답 목록·말하기 모드 설정은 브라우저의 로컬 저장소에 저장합니다. 기존 HTML의 같은 브라우저·같은 출처 기록이 있으면 최초에 읽어옵니다. 파일 실행과 웹 실행, 다른 브라우저는 저장 위치가 달라 기록이 자동 공유되지 않습니다. 오답은 해당 단계를 다시 맞히면 목록에서 빠집니다. 오답 복습은 한 번에 최대 15단계입니다. 결과는 이 게임의 정답률이며 실제 실기시험 합격 판정이 아닙니다.

## 수정할 파일

`dist/index.html`: 기본 화면 구조. `dist/style.css`: 색상·배치·반응형 디자인. `dist/app.js`: ADV 진행·대사 읽기·말하기 연습·녹음·복습·기록. `dist/training-data.json`: 편집하기 쉬운 학습 데이터. `dist/data.js`: 로컬에서도 읽을 수 있도록 동일 데이터를 포함한 실행용 파일. 데이터를 수정할 때는 training-data.json과 data.js를 함께 갱신하세요.

## 검증

전체 74개 시나리오의 원문 데이터 일치, 432단계 렌더링·정답 채점·결과 처리, 선택지별 대사 존재 및 중복, 오답 복습·해소, 말하기 모드에서 숨긴 선택지 응답 차단을 자동 검증했습니다. 실제 브라우저에서 에셋 표시, 인물 전환, 정답·오답 해설, 직접 쓴 지령 비교, 시나리오 검색, 기록 저장 후 재실행, 복습 결과를 확인했습니다. 실제 마이크 녹음과 OS 한국어 음성 출력은 기기 권한·음성 지원에 따라 달라 별도 확인이 필요합니다.

## 대화 개선판
- 74개 사고 도입과 호출 대상을 표시하고, 상황 진행 설명과 상대의 실제 대사를 분리했습니다.
- 432단계 수신 대사와 1,728개 선택 대사에 Claude 버전의 구체적인 호출·응답을 반영했습니다.
- 선택 후 상대 응답을 확인하고 다시 들을 수 있습니다. 오답일 때는 정답을 보냈을 때의 응답 예시임을 표시합니다.
- 감독관 질문 61단계는 현장 무전과 구분하고, 먼저 말하기 모드에서도 구술 답변 안내를 제공합니다.
- 원본 조치·정답·해설·근거 쪽수와 고화질 PNG 20장은 유지했습니다. Claude ZIP의 JPG는 사용하지 않았습니다.
- 추가 상황·대사는 학습용 각색입니다. 공식 표준 무전 문구나 시험 채점 기준을 의미하지 않습니다.

## ADV 대사 연출 (현재 화면)

원래 오르페이아의 청록색 디자인과 고화질 PNG를 사용합니다. 홀로그램 아래 대화창에서 실제 보고가 한 글자씩 표시되고 문장부호에서 잠시 쉽니다.

현장 보고 → 4개 행동·대사 선택 → 내가 고른 지령의 송신 → 상대 복창 → 해설 순서로 진행합니다. 보고 중에는 선택지를 표시하지 않고, 송신·복창 중에는 해설과 정답을 미리 보여주지 않습니다.

- 대화창 클릭 또는 Enter/Space: 현재 대사를 즉시 표시합니다. 이미 표시가 끝났다면 다음 교신 연출로 진행합니다.
- 대사 속도: 여유롭게 / 보통 / 빠르게 / 즉시 표시. 브라우저에 설정을 저장합니다.
- 숫자 1~4: 선택지가 공개된 응답 차례에서만 선택합니다. 키를 길게 눌러도 중복 선택되지 않습니다.
- 먼저 말하기: 보고가 끝나면 메모·45초 연습·녹음 화면을 표시합니다. ‘선택지 확인’을 눌러 답을 고릅니다.
- 교신 기록: 완료된 수신·송신·응답을 말풍선으로 다시 읽습니다.
- 창을 벗어나거나 시나리오 목록을 열면 대사 연출을 일시 정지하고 돌아오면 이어갑니다.
- 운영체제의 동작 줄이기를 사용하는 경우 기본 대사 속도는 즉시 표시이며 반복 애니메이션을 끕니다.

대사 읽기는 ‘현재 대사 듣기’를 눌러 사용할 수 있습니다. 타이핑 연출과 음성 읽기는 별도 기능이며, 실제 마이크 녹음·음성 출력의 청취 검사는 하지 않았습니다.

타이핑 진행, 문장 단계 전환, 선택·해설의 조기 노출 방지, 중복 선택 차단, 건너뛰기, 목록·화면 전환 시 타이머 정리, 즉시 표시와 먼저 말하기를 검사했습니다. 전체 432단계 채점 검사와 데스크톱·390px 모바일 화면 확인을 완료했습니다.

## 장면 위 선택지와 실패 엔딩 (현재 동작)

보고가 끝나면 장면 중앙에 질문과 4개의 지령 선택지가 겹쳐 나타납니다. 대화창은 화면 아래에 있습니다. 긴 선택지는 선택지 영역 안에서 스크롤할 수 있고, 숫자 1~4로도 고릅니다. 먼저 말하기 모드에서는 같은 위치에 발화 연습 화면을 표시한 뒤 선택지를 공개합니다.

정답을 고르면 내 송신 → 상대 복창 → 해설 → 다음 보고로 이어집니다. 오답을 고르면 내 송신 → 실패 엔딩 대사 → GAME OVER로 종료됩니다. ‘이 시나리오 처음부터 다시 출동’ 또는 Enter를 누르면 해당 시나리오의 1단계부터 재시작합니다. 실패한 단계에서 계속 진행하는 버튼은 없습니다. 오답 복습 중 실패해도 원래 시나리오 전체의 처음으로 돌아갑니다.

실패 엔딩은 선택한 오답 조치와 사고 유형을 연결한 학습용 가상 분기입니다. 충돌·화재·전력·신호·재해·위험물 등의 최악의 전개를 가정하며, 교재 원문 해설과 구분합니다. GAME OVER의 ‘실패 이유와 정답 지령 확인’에서 원래 해설·정답 대사·근거 쪽수를 확인할 수 있습니다. 재시작하면 이번 진행·선택·메모는 초기화하고 오답 기록과 대사 속도·말하기 설정은 유지합니다.

전체 1,296개 오답 분기의 GAME OVER·처음부터 재시작과 432개 정답 경로를 검사했습니다. 실제 화면에서 중앙 선택지, 게임오버와 첫 단계 재시작을 확인했고, 390px 모바일에서 가로 넘침이 없음을 확인했습니다. 그림은 기존 고화질 PNG 원본입니다.


## CG 연출 업데이트
- 새 CG 34장을 원본 PNG 그대로 포함했습니다. 배경·인물·연결 효과를 분리해 교신 단계에 맞춰 표시합니다.
- 주요 보고 6종, 실패 엔딩 4종, 훈련 완료 CG를 연결했습니다.
- 상단 CG 갤러리에서 34장 전체를 감상하고 원본을 저장할 수 있습니다. 훈련 중 ‘CG 감상’은 현재 장면을 열며, 감상 동안 대사 연출이 멈춥니다.
- 선택창과 메인 대사창의 불투명도는 35%로 고정했습니다. 조절 게이지와 선택지 상단 안내창은 제거했습니다.
- 정답 근거·정답 지령·다음 수신 버튼은 CG 화면 안에서 확인합니다. 기록·근거는 게임 화면 위 팝업으로 엽니다.
- ZIP은 dist/index.html을 열어 실행할 수 있습니다. 단일 HTML도 모든 이미지를 포함합니다.
