# CTC LAB 열차 움직임 기능 점검

게임에 열차 움직임을 붙이면서 CTC LAB(`simulator/engine/scenario-motion.js`, 내장본 기준 v0.39.58)의 움직임 기능을 읽고 돌려 본 결과다. 비상시조치 05-1 문제(FTS `SC-em-05-1`)의 초기 배치에서 시험했다.

## 잘 되는 것

| 기능 | 확인한 동작 |
|---|---|
| 진로를 따라 이동 | 승강장에서 출발할 때 출발진로를 찾아 점유한다. AUTO면 진로를 스스로 잡는다(예: K1210 금천구청 5T → `3B-B963T`). |
| 역 사이 인계 | 폐색 열번창에서 다음 역 화면의 열번창으로 넘어간다(금천구청 B963T → 구로 B959T). |
| 본선 이어 달리기 | 상1선 A0168에 출발 요청 하나를 주면 금천구청 4T → 구로 2T → 영등포 3T → 노량진까지 진로를 잡으며 계속 달린다. |
| 앞이 막히면 대기 | 고장열차 뒤 폐색에서 「전방 폐색에 선행열차 K1208 · 통과 대기」로 멈춘다. 대기 이유가 작업마다 글로 남는다. |
| 수동 이동으로 취소 | 열번을 손으로 옮기면 그 열차의 남은 이동이 취소된다. 게임의 되감기에 이걸 쓴다. |
| 화면 표시 | 이동 중인 구간이 빨간 점유로 표시되고, 도착하면 열번창에 번호가 뜬다. |

## 부족하거나 주의할 것

1. **본선이 갈리는 역 앞에서 열차가 사라진다.**
   - `onward()`는 다음 역의 본선에 승강장 선로가 둘 이상이면(구로 상2선 `4T·5T`, 용산) 경로를 만들지 않고 끝낸다. 그러면 출발 요청은 곧바로 「관제구간 밖으로」 처리된다.
   - 결과: 상2선 금천구청 → 구로 방향 열차는 출발진로 하나만 지나고 화면에서 사라진다. 독산·가산디지털 구간(B959T, B957T)을 달리지 않는다.
   - 차량고장 대본(05, 05-1)의 사고 구간이 바로 이 구간이라, 후속열차가 고장열차 뒤로 다가오는 장면이 나오지 않는다.
   - 제안: 다음 역이 여러 선로로 갈리더라도 **그 역 장내신호기 앞 열번창까지는 달리게** 하고, 거기서 진로를 기다리게 한다.
   - 지금 게임에서는 장면이 구간별 이동(`move`)을 직접 지시해서 피해 간다.

2. **승강장을 떠나는 조건이 실제보다 보수적이다.**
   - 다음 역 장내 앞까지의 폐색이 모두 비어 있어야 출발한다(`clear`). 코드 주석에 「폐색 한가운데 서서 남의 진로를 막지 않는다」는 의도가 적혀 있다.
   - 실제로는 출발신호가 진행이면 떠나고 폐색신호마다 멈춘다. 그래서 「통제하지 않으면 열차가 역 사이에 선다」는 상황이 이어 달리기만으로는 재현되지 않는다.
   - 의도한 설계라면 그대로 두어도 된다. 다만 교육 목적상 「역 사이에 갇히는 열차」를 보여 주려면 선택지가 필요하다.

3. **구간마다 걸리는 시간이 20초로 같다.** 폐색 길이나 역 간 거리와 상관없다. 열차 간격이 실제와 다르게 보인다.

4. **이동 중에는 열차번호가 보이지 않는다.** 빨간 점유만 움직이고 번호는 도착한 뒤에 뜬다. 여러 열차가 동시에 움직이면 어느 열차인지 알기 어렵다.

5. **달리는 열차를 세우는 명령이 없다.** 지금은 열번 수동 이동으로 취소하는 방법뿐이다. 「○○역 정차」 지시를 엔진이 직접 받는 명령(예: 다음 역 승강장에서 이동 종료)이 있으면 FTS 문제에서도 쓸 수 있다.

6. **등록되지 않은 폐색에는 갈 수 없다.** 구로 화면 상2선에는 B953T·B957T·B959T만 열번창으로 등록되어 있다. B955T, B961T로 이동을 요청하면 「등록된 열번창을 선택하세요」로 거부된다. 오류는 아니지만, 이동 경로를 짤 때 창 목록(`SimTrainWindows.data`)을 확인해야 한다.

## 게임에서 쓰는 방식

- 통제를 놓치면(게이지가 바닥나면) 그 열차의 이동 구간을 지시하고, 시계를 8배속으로 돌려 LS에서 다가오는 모습을 보여 준 뒤 결말을 띄운다. 되감으면 열번을 원래 자리로 옮긴다.
- 인접선 A0168은 주의운전을 지시하면 이어 달리기로 고장 지점 옆을 지나간다.
- 마지막에 복구를 통보하면 K1208이 떠나고, 세워 둔 K1210·K1212가 다시 움직인다.
