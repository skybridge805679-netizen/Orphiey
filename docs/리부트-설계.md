# 리부트 설계 — 실전 LS·MMI 무전극 VN

## 결정 사항

| 항목 | 결정 |
|---|---|
| 본편 시나리오 | CTC LAB의 교육장 실전 시나리오 19문제 (아래 표) |
| 교재 74문제 | 부록 「교재 문제집」으로 남김 (타이틀 메뉴, 처음부터 전부 열림) |
| 무대 | 실제 수도권 1호선(청량리~수원)과 관제교육장 배선, 실제 역명 |
| 시뮬레이터 | CTC LAB `simulator/`를 `ctc/`에 복사해 내장 (수정 내역은 `ctc/ORPHEIA-VENDOR.md`) |
| 화면 | 데스크톱 전용 (휴대폰은 고려하지 않음) |
| 이전 스토리 | `story/legacy/`에 보관 (불러오지 않음) |

## 실습 화면 구조

```
┌───────────────────────────────────────────────┐
│  CTC LAB LS·MMI (iframe, 실제 조작)            │
│  — 진로·신호·선로전환기·열번·스케줄            │
├──────────┬──────────────────────┬─────────────┤
│ 화자 얼굴 │ 이름표(배역 · 배우)   │ 문제명·진행률 │
│          │ 대사 / 선택지          │ 조작 대기 표시 │
│          │                       │ 힌트·무전 기록 │
└──────────┴──────────────────────┴─────────────┘
```

- `@ctc <시나리오ID>`: 대본 명령. 시뮬레이터를 새로 띄우고(깨끗한 LS) 시나리오를 시작한다.
- 시뮬레이터의 대본 단계는 그대로 쓴다.
  - **통보(say) 단계**: 원문 무전을 화자별 대사로 나눠 재생한다. 관제 차례에서 플레이어가 무엇을 말할지 고른다.
  - **조작(do) 단계**: 플레이어가 LS·MMI를 직접 조작하고, 시뮬레이터가 인식하면 다음으로 넘어간다.
- 대피 시나리오는 시간표가 필요해서, FTS의 문제별 시간표(`SimFTSBuiltins.timetableFor`)를 먼저 넣는다.

### 무전 역할극 배역

교육장에서는 교수가 상대역을 맡는다. 이야기에서는 등장인물이 역할극으로 맡는다.

| 원문 화자 | 배역 | 배우 | 이유 |
|---|---|---|---|
| (관) | 관제사 | 신상철 (플레이어) | — |
| (기), 충돌열차 | ○○○○ 기관사 | 유하린 | 기관사 7년 차 출신 |
| (○○역), 역/열차 | ○○역 | 류지안 | 금천구청역 부역장 출신 |
| 관제팀장, 관제운영실 | 관제팀장·운영실 | 서도희 교수 | 교수가 상위 보고를 받는 역할 |
| 사고복구반, 기동검수반 | 복구반·검수반 | 오르페이아 | 작업복 의상(engineer)으로 연기 |

원문 화자 집계(비상 9종): 관 511, 기 292, 사고복구반 26, 관제팀장 15, 각 역 50여, 기동검수반 8.

### 선택지 규칙

- 한 통보 단계에서 **처음으로 내용이 있는 관제 발화**가 선택 지점이다. 「철도관제 이상!」 같은 단순 응답은 자동으로 말한다.
- 오답 2개는 같은 시나리오의 **다른 단계 첫 발화**에서 가져온다. 주로 너무 이른 무전이다.
  - 그래서 「이 순간에 나가야 할 말이 아니었다」를 그대로 연습하게 된다.
- 오답을 고르면 「0.3초 예측 연산」으로 나비효과 미래를 보여 준 뒤 되감는다. 고른 오답은 지워진다.
- 힌트를 켜면 정답 선택지에 색이 들어가고 단계명이 보인다. 조작 단계에서는 해야 할 조작과 방법이 보인다.
- 힌트를 끄면 조작 단계에서 「무엇을 해야 하죠?」 버튼으로만 볼 수 있다. 본 횟수는 결과에 기록된다.

### 원문 정리 규칙 (ctc-drill.js `utterances`)

- `(기)`, `(관)`, `(석수역)`, `관)`(오타)이 새 발화를 시작한다. 들여쓴 줄은 이어지는 말이다.
- 줄 전체가 괄호인 줄은 대체 표현이나 지문이라 제외한다. 대사 뒤에 2칸 이상 띄우고 붙은 괄호도 제외한다.
- `※` 운영자 메모와 그 뒷줄, 페이지 번호 줄(`05-2-1`)을 제외한다. `(_수신 이상!_)` 표기는 대사로 살린다.

## 필요한 에셋 (추가 예정)

- `bg_training_room`: 관제 실습실. 지금은 `bg_exam_hall`(실기 평가장·시뮬레이터실)로 대신한다.
- 역할극 소품을 단 스탠딩

  - 서 교수: 팀장 명패
- 무전 채널 표시 아이콘 (열차무선, 역 무선, 유선)
