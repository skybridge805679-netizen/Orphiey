# 또 다른 도입 — 아직 출발시키지 마세요

저장소 루트에서 `python3 -m http.server 8765` 실행 후 `/alternate/`에서 플레이합니다. 기존 메인 화면의 **다른 도입 체험** 링크로도 진입할 수 있습니다.

관제교육 이수 중인 플레이어를 대상으로 한 독립 도입입니다. 인수인계 대화 → 고장 보고 → 후속열차 교신과 출발신호 취급 → 인계와 인물 반응까지 플레이할 수 있습니다. 대화는 수동 진행하며 통보와 설비 취급 순서에 따라 상대의 반응이 달라집니다. 성적이나 실패 예측으로 중단하지 않습니다.

## 구현 범위

- 기존 `SimCore.forStation('geumcheon')`의 독립 초기 상태에서 제어권과 3B 진로/신호를 처리합니다. 초기 진로는 `3B-B639T`입니다.
- `ctc/index.html`을 숨겨진 iframe으로 로드하여 기존 엔진을 사용합니다. 별도 시나리오 상태이므로 기존 VN 저장을 쓰지 않습니다.
- 표시반은 정밀 배선도가 아닌 이야기용 개요도입니다. 열차 위치와 교신은 시나리오 연출이며, 실제 시간표 운행/열차 이동/FTS 채점은 연결하지 않았습니다.
- 완결된 비상조치 교육과정이 아니라 후속열차 출발 보류까지의 도입 실험입니다. 운행선 변경과 복구는 구현 범위 밖입니다.
- 인물 이미지는 기존 에셋을 재사용했습니다. 새 이야기와 UI는 이 디렉터리에 분리했습니다.

## 확인

서버 실행 상태에서 `node alternate/smoke.cjs` (Playwright와 `/usr/bin/chromium` 필요).
통보 후 취급, 취급 후 통보, AUTO 상태의 취급 거부, AUTO 복귀 후 종료, 런타임 오류/HTTP 오류, 모바일 가로 넘침을 확인합니다.
